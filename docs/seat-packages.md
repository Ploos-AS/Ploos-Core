# Seat package policy

Suggested fixed bands: Solo 1, Starter 5, Standard 10, Plus 25, Pro 50, Business 100. Enterprise is individually configured, not an unlimited entitlement.

Starter is the default suggested organization package. Solo is an optional single-user offer. Products without per-user licensing need not use these bands. Provider-specific contracts and actual plan seat_limit remain authoritative. Organization membership is not equivalent to a paid mailbox or workspace seat.

The helper defines package sizes only. No commercial plans, prices, providers or orders are activated. Additional seats require explicit plan and entitlement policy; atomic allocation and billing reconciliation remain pending.
