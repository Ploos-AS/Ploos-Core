# Forenio integration boundary

Forenio's upstream README guarantees a free, accountless formation wizard with local processing. Core must not receive wizard drafts, personal data, telemetry or mandatory signup requests from that flow.

Optional paid association administration is a separate opt-in flow. Core can manage organizations, subscriptions and independent services after authenticated onboarding. An association owner or administrator may manage services; billing and ownership changes retain the stricter Core authorization rules.

The eligibility helper applies only to existing Core association organizations. It does not establish legal representation or verify a public registration. Future integration requires explicit consent, verified authority, trusted identity mapping, data minimization and a separate onboarding endpoint. No Forenio changes, API calls or automatic orders are introduced.
