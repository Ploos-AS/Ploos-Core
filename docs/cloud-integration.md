# Ploos Cloud integration boundary

The upstream Ploos-AS/Ploos-Cloud README defines three planned tracks: Office (Infomaniak kSuite), Privacy (Proton), and Drive (Ploos-managed Nextcloud). Core maps these to its existing provider codes under product cloud.

Drive may later have distinct Norwegian and European hosting plans, subject to verified infrastructure and data residency. Five-seat organization packages are a proposed commercial default, not an upstream licensing promise.

The upstream project is pre-MVP and prioritizes assisted onboarding and a non-production Nextcloud pilot. Core must not enable ordering, register live provisioning adapters, or imply reseller status until contracts, APIs and operational readiness are verified. This change introduces only a track mapping; no provider API calls, plan activation, or automated onboarding.
